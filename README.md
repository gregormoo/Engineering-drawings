# Engineering drawings

Turns CAD parts into dimensioned engineering drawings (PDF) with orthographic views, hidden lines, hole callouts and an ISO title block.

## Skills

- `.claude/skills/engineering-drawing/`: vendored from [earthtojake/text-to-cad](https://github.com/earthtojake/text-to-cad) at commit `a7cf2c470e345d6b6a2fe373a73e0420ff64ad2a` (MIT), the same pin `nuroctane/nur-cli` installs. The skill drives the `cadgen` Python package (`cadgen==0.8.2` from PyPI).
